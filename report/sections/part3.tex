\section{Individual contributions: group completion required}

The guideline requires an identified author for every project-code and report section, agreed individual contribution percentages, and transparent attribution. Repository commit authorship alone does not prove agreed assessed contributions, and this document does not invent names or shares. The group must complete the following collaboratively before any independently written submission \cite{source16}.
