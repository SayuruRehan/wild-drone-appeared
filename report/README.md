# COMP6008 report research materials

This directory is intended for a LaTeX-based research dossier. The assignment prohibits generative AI in submitted work; students must independently write and attribute assessed material.

A complete local LaTeX source package and compiled PDF have been prepared. Build command: `xelatex -interaction=nonstopmode -halt-on-error main.tex` (twice). The repo upload of remaining sources/PDF has not yet completed.
